# Sistem Informasi Laporan Laba Rugi

Website Sistem Informasi Laporan Laba Rugi Pada Unit Usaha Fotokopi Jayadirana.

## Teknologi

- Laravel
- PHP
- MySQL
- Bootstrap

## Deskripsi

Website ini dibuat untuk membantu pengelolaan laporan laba rugi Unit Usaha Fotokopi Jayadirana. Sistem menyediakan fitur pengelolaan pendapatan, pengeluaran, laporan laba rugi, riwayat laporan, dan manajemen akun berdasarkan hak akses Admin dan Direktur.
